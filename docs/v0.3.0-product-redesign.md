# v0.3.0 product redesign

## Architecture

The default screen exposes only three actions: **Find Your Game**, **Pick Your Picture**, and **Apply It**. Window helpers and technical package controls stay collapsed until requested.

## Beginner flow

1. The app tries to find BPSR automatically; manual folder selection is always available.
2. The user chooses Square or Card, selects an image, and adjusts a drag/zoom crop.
3. **Use This Picture** handles target discovery, backup, verification, and installation automatically.

## Detection logic

Any Texture2D named `personalzone_player_bg_1` through `personalzone_player_bg_20` is valid. Search stops at the first valid slot. The previous working package/bundle/slot is cached. Optional Discord `fileNNN` input is only a speed hint and automatically falls back to normal scanning when stale.

## Error prevention

Apply is disabled until a valid game folder and a crop matching the selected Square/Card shape exist. Manual game-folder selection overrides automatic detection. The live package is only replaced after the rebuilt package passes structural and target-slot verification.
