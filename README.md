# BPSR Custom PFP Lite

Windows tool for preparing a custom **Blue Protocol: Star Resonance** profile picture or card, with cropping, numbered instructions, backups and restoration.

[Download Windows build](https://github.com/Zudin987/BPSR-CustomPFP-Lite/releases/latest) · [Project website](https://zudin987.github.io/projects/custompfp/) · [Report an issue](https://github.com/Zudin987/BPSR-CustomPFP-Lite/issues)

## Before you start

You need Windows, an installed copy of BPSR and the image you want to use. The release EXE does not require a separate Python installation.

**This method temporarily modifies a BPSR client file. It is unofficial and is not guaranteed ban-safe.** Keep the app's backup and complete the restore step when finished.

## Create your portrait or card

1. Download the Windows ZIP from Releases and extract it.
2. Open the app and find your BPSR folder.
3. Choose Square or Card, then select and crop your picture.
4. Follow the small numbered steps shown in the app.
5. Save the portrait or card in BPSR.
6. Restore the original BPSR file when finished.

Your selected images and backups stay on your PC.

## If something changes or fails

- **The game folder is not detected:** select your actual BPSR installation folder manually in the app.
- **The app refuses to restore:** keep the backup and follow its recovery guidance. Do not force an old backup over an unknown game file.
- **BPSR updated while a custom file was active:** close the game and use the launcher/Steam **Verify or Repair** feature instead of forcing the backup.

When reporting a problem, include the app version, game region, numbered step and exact error message.
